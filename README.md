# 福岡市長選2026 候補者DB

福岡市長選挙(2026年11月15日投開票)の候補者・公約・市の計画を、出典付きで整理した静的ページです。

- 公開ページ: https://mandrill-fukuoka.github.io/fukuoka-mayor-2026/
- 市のマスタープラン解説: https://mandrill-fukuoka.github.io/fukuoka-mayor-2026/masterplan.html

## 方針

- 報道と公表資料の事実だけを、出典付きで載せます。評価や予想、思想ラベルは載せません。
- 候補者の色は50音順の識別用で、政党や立場とは無関係です。
- 誤りや修正のご指摘は、Issuesへお願いします。

## 構成

- `index.html` : 候補者DB本体(データは `CANDS` / `STM` / `PLEDGES` の配列)
- `masterplan.html` : 福岡市のマスタープラン解説
